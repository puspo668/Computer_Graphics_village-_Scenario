Village Scenario – Computer Graphics

A 2D Village Scenario project developed using Computer Graphics concepts. The project creates a simple village environment by combining different graphical objects and shapes.

🌾 Project Overview

The scene represents a rural village environment containing elements such as:

* 🏠 Houses
* 🌳 Trees
* 🌞 Sun
* ☁️ Clouds
* 🌾 Fields
* 🛣️ Roads
* 🌊 Water / River
* Other village-related objects

 🛠️ Technologies Used

* C++
* OpenGL / GLUT
* Code::Blocks

🎯 Objectives

* Apply fundamental Computer Graphics concepts in a practical project
* Create and manipulate 2D graphical objects
* Understand coordinate systems and transformations
* Develop a complete graphical scene using programming

▶️ How to Run

1. Clone or download this repository.
2. Open the project in **Code::Blocks**.
3. Make sure OpenGL/GLUT is properly configured.
4. Build and run the project.
